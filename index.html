Docker Monitoring Stack
GitHub

Host monitoring with Prometheus, Grafana and Node Exporter, started with one docker compose command. Prometheus collects CPU, memory, disk and network metrics every 15 seconds and Grafana gets its data source from provisioning files. The containers share their own bridge network, data sits in named volumes and the Grafana login stays in a .env file outside the repository.

GitHub

Uptime monitor on Azure Functions (Python). It checks 12 websites every 5 minutes, stores the status code and response time in Table Storage, shows them on a static dashboard and sends an email through Logic Apps when a site goes down. The infrastructure is modular Terraform with remote state, checked by GitHub Actions. The demo is offline since the Azure subscription was closed; the repository has screenshots.
